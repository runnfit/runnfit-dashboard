📋 출석 대시보드 1분 설치

한 번만 설치하면, 다짐매니저가 켜져 있을 때 북마크 클릭 한 번으로 대시보드를 볼 수 있어요.
대시보드가 업데이트돼도 다시 설치할 필요 없어요. 누를 때마다 항상 최신 버전이 떠요.

1

크롬 북마크바 켜기

크롬에서 맥은 Cmd + Shift + B, 윈도우는 Ctrl + Shift + B 를 누르면 주소창 아래에 북마크바가 생겨요.

2

아래 버튼을 북마크바로 끌어다 놓기

버튼을 누르지 말고, 마우스로 꾹 잡아서 북마크바 위에 놓아주세요.

🏃 런앤핏 출석
↑ 이 버튼을 북마크바로 드래그
3

다짐매니저 켜고 북마크 클릭

다짐매니저에 로그인한 화면에서 북마크바의 🏃 런앤핏 출석을 누르면 대시보드가 떠요.
닫을 땐 ✕ 닫기, ESC, 또는 북마크를 한 번 더 누르면 돼요.

끌어다 놓기가 안 될 때 (직접 북마크 만들기)
  1. 아래 코드 복사를 눌러요.
  2. 북마크바에서 마우스 오른쪽 클릭 → 페이지 추가 (윈도우: 페이지 추가…)
  3. 이름: 🏃 런앤핏 출석 / URL 칸에 붙여넣기 → 저장
🔒 다짐매니저에 로그인한 사람에게만 회원 정보가 보여요. 이 북마크와 대시보드 파일에는 회원 정보가 들어 있지 않고, 화면에 띄운 정보는 어디에도 저장되지 않아요.
